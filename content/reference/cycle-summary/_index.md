# Appendix E: Cycle Summary (Reference, Not Rules)

| Scope | Unit | Ends With | Notes |
|-------|------|-----------|-------|
| [Task](/reference/ubiq/#task) | Smallest actionable unit | Task complete | No constraint on count |
| [Test](/reference/ubiq/#test) | One behaviour scenario | Test written + reviewed | One per [Gherkin](/reference/ubiq/#gherkin) scenario |
| [Use Case](/reference/ubiq/#use-case) | Structured goal-level spec | Scenarios written + Tests written + Tasks defined | One per [Aggregate](/reference/ubiq/#aggregate) |
| [Story](/reference/ubiq/#story) | Value placeholder | Prioritised + accepted | Maps to 0+ Use Cases |
| [Delivery](/reference/ubiq/#delivery) | Coherent batch of use cases | [Release](/reference/ubiq/#release) | No constraint on duration |
| [Direction](/reference/ubiq/#direction) | Continuous | Revisited regularly | Not a closed loop |
